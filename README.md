# Portfolio Website - Google Search Result Page Style

This repository contains the source code for my portfolio website, inspired by the **Google** Search Result Page as it appeared in early 2024. Built with **HTML**, **CSS**, and **JavaScript**, the website serves as a unique representation of my work and skills.

---

## Features 🚀

- **Google Search Page Inspired Design**:
  - Mimics the look and feel of the Google search results layout.
- **Responsive Layout**:
  - Optimized for desktop and mobile devices.
- **Dynamic and Interactive Elements**:
  - Utilizes JavaScript for smooth user interactions.
- **Clean UI/UX**:
  - Focused on simplicity and ease of navigation.

---

## Technologies Used 🛠️

- **HTML5**
- **CSS3**
  - Flexbox for layout alignment.
  - Custom animations and styles.
- **JavaScript**
  - For dynamic interactions.

---

## Installation 💻

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mohammadsarfarazafzal/portfolio-google-style.git
   cd portfolio-google-style
   ```

2. **Open the project**:
   Open the `index.html` file in any modern web browser.

3. **Explore the website**:
   Interact with the elements, and experience the Google-inspired design.
